# 更明显的侧向点头 · 对比稿

打开 `index.html`：左边是用户已认可的「头部轻晃」，右边是新绘的侧向点头。三套可切换，默认 0.25×，支持暂停、逐帧、放大和深浅背景。

目标是头部带上身往一侧轻压、回正、再往另一侧轻压；脸仍保持原朝向。保留圆凳、坐向与十二帧摆腿设计。均为完整人物绘画，未拆分头部或腿部做旋转，未叠帧。

此稿只用于比较，未写入正式动画资源。0.8.9 设置提供的是上一版已认可的「头部轻晃」，不是本目录的新点头稿。

图片通过内置 ImageGen 编辑，初始提示保存在 `prompts.json`，冬祈新愿最终修订见 `winter-revision.json`。生成式修绘存在局部线条差异，不承诺下半身像素完全一致。图集按完整连通人物裁切，并沿用同一套位置和比例校准，不以新头部重新居中；额外留白仅用于对比，便于检查完整轮廓。
