# 时砾逐光·圆润Q版（清晰动作版）

以用户确认的四姿态校样为准，内置 imagegen 分批生成动作，再缩小至原生帧尺寸；站立、眨眼、基础挥手及开心姿态直接复用获认可的校样像素。

图集1536×2288，每格192×208。包含客户端73个必需槽位，另保留1个待机兼容槽。每套24张绘制关键姿态，经保持帧、循环、位移与跑动镜像编排，非74张独立绘画。八种视线变化映射至16个方向槽位。

安装器覆盖相同ID前自动备份旧版。设置 → 宠物 → 刷新；若仍缓存旧图，可切换宠物或重启应用。

角色与服装来自《崩坏3》。AI同人作品，圆润Q版视觉方向参考南澄酱_水母水母水公开展示，但明亮眼神与动作根据用户确认版本调整，非画师本人作品或背书。

尺寸、透明通道、槽位及与校样一致性已验证；另提供按本机客户端时序播放的离线预览。
