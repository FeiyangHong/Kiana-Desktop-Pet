# 日常动作生成记录

使用内置 image_gen（imagegen 技能），以已确认的四姿态高清图为角色参考。原图保存在本目录；assets 内为工程裁切排版后的透明图集，每帧 384×416，同一套使用统一缩放比例，保留原始 alpha，不重绘或锐化。

Create ONE clean PNG sheet, 2 columns x 2 rows, FOUR full-body frames, each character about 600 pixels tall, generously separated transparent cells. Top row: tidying hair animation, frame A her right hand gently lifting to touch side fringe, frame B smoothing fringe smiling warmly. Bottom row: stretching animation, frame A arms up beside head beginning stretch, frame B arms gently stretched above head and body very slightly taller, bright happy expression. Preserve EXACT outfit, ice-blue crystal crown, snowy silver-white twin braids, blue/white dress, body/head proportions and face style. Do not include any of the original reference poses unchanged.
