# 冬祈新愿

《崩坏3》琪亚娜「咚！炽愿吉星」服装「冬祈新愿」的 AI 辅助生成 Q 版同人桌宠。

安装：将本目录放入 ~/.codex/pets/，在应用的设置 → 宠物 → 我的宠物旁点击刷新并选择。

与参考仓库相同的 1536×2288 透明图集、192×208 单帧、11 行格式；包含 9 组状态与 16 个视线槽位。实际动作由客户端触发，视线差异较细微。未包含仓库额外的注入增强器。

风格参考：https://github.com/3073717189/Codex-Kiana-Pet-Enhancer

新图像由内置 imagegen 生成，后续仅做分帧尺寸统一、基线对齐及无损 WebP 打包。非官方游戏原画，细节是 Q 版同人化演绎。
