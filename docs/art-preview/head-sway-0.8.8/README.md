# 坐姿听歌：头部与上身轻晃对比稿

双击 `index.html` 离线查看。三套 Q 版左右同步播放，可暂停、逐帧、放大头部及切换深浅背景。默认沿用坐姿 0.25×，一轮 9.6 秒。

本轮只制作预览，未替换正式 `assets`、未更改程序或个人设置，当前安装仍为 0.8.8。

- `*-before.png`：0.8.8 已安装坐姿源图快照。
- `*-after.png`：使用内置 image_gen 修绘的十二帧试稿。参考用户两张图片的轻侧倾、回正与点头，增加头颈、肩膀及上身动作；保留原坐向、圆凳和逐格摆腿设计。眼睛沿用原来的睁眼神态、虹膜配色和星形高光。
- `*-display.png`：以相同的 0.8.8 校准位置与缩放渲染的整帧对比图集；不按新头部重新居中，不拆分或旋转肢体，不使用透明叠帧。完整轮廓裁切避免倾斜头饰跨越规则网格时被截掉。
- `comparison.png`：三套当前版第一帧与试稿第1、6、12帧的静态对比。
- `base-calibration.json`、`crops.json`：坐姿基线与完整轮廓裁切记录。
- `prompts.json`：实际使用的生成提示。冬祈新愿第一轮只有九帧且改动了腿部，已舍弃，目录中是修订后的十二帧版本。

生成式修绘并非局部像素完全锁定，下半身沿用原动作设计但可能有细微线条变化；可在相同帧位并排检查。用户提供的图片只作为动作参考，不用于改变角色画风。
