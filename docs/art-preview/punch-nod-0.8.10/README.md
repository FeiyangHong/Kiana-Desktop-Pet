# 有力点头与冬祈新愿修色对比

打开 `index.html`，在「对比内容」切换三套有力点头、冬祈新愿轻晃修色、冬祈新愿侧向点头修色。

- 有力点头：左边已认可的侧向点头，右边新绘试稿；点下更快、低点稍停、回弹较慢。支持与均匀播放比较。两种节奏一轮都为 9.6 秒，默认 0.25×。不同帧停留时间也作用于完整人物，不拆开头部或肢体。
- 修色对比：左边普通坐姿作为画风和颜色基准，中间修正前，右边修正后。保留认可的头部和身体动作，调整描边、阴影、头发、肤色及服装绘画表现。
- 支持暂停、逐张绘画、时间轴、头部放大和深浅背景。逐帧对照时左右切到同一绘画编号；正常播放按各自动画顺序。

0.8.10 已安装的是「原版坐姿／头部轻晃／侧向点头」三个选项，包含冬祈新愿的画风修正。本目录的**有力点头仅作新校样，未放入正式运行资产**。

均由内置 ImageGen 生成或编辑，提示、取舍和播放节奏保存在 `prompts.json`。整体人物比例、脸的朝向及不对称发型经过对照检查；生成式修绘仍可能留下局部线条差异，不宣称下半身逐像素一致。时砾逐光有力点头稿修复了错误镜像姿势与底部鞋尖裁切。

`*-display.png` 为完整人物裁切后用于浏览器的图集，保留平滑采样与透明度。`comparison.png` 为三套关键帧，`winter-style-comparison.png` 为冬祈新愿修色静态对照。运行资产另有校准数据，为整组帧预留边缘空间，不逐帧重新居中头部。
