# 测试运行

完整解压安装包后，在 Windows PowerShell 中运行本目录 Run-Tests.ps1。需要 .NET Framework 4.8，自带编译器会在临时目录编译测试程序。

测试使用独立状态目录，窗口测试可能短暂显示预览界面、移动鼠标后恢复，不控制真实音乐播放，也不修改已安装桌宠的偏好。测试目录和 JSON 报告会保留在命令输出的位置，便于查看。`-Names usability-tests` 可只运行某一组。

随包 0.6.0校验记录.json 另包含升级执行器隔离测试；其替身目录切换验证在开发工作区完成。物理触屏和真实混合 DPI 多屏不在自动用例覆盖范围内。
