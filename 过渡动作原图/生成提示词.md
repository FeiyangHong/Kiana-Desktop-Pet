# 0.6.0 过渡动作

使用 Codex 内置 `image_gen` 工具，以对应服装的已确认「日常动作原图」为参考，各生成一张四帧透明原图。没有调用独立图像 API。

三套服装共 12 张新过渡姿态：整理头发开始抬手、手抬到脸侧；伸懒腰开始屈臂、手抬到肩部。与已有关键帧组成约 2.1 秒的来回动作。

实际原图为 1254×1254；运行图集为 768×832，每帧 384×416。工程处理仅按透明轮廓裁切、每套统一比例缩放、对齐脚底并排版；保留 RGBA，不加锐化、不抠掉绘制细节。图片背景为真透明。
