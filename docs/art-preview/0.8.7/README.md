# 圆凳与过渡动画试稿

双击 `index.html` 可离线查看三套 Q 版的同步动态对比，支持坐姿、坐下、起身、完整流程、暂停逐帧及深浅背景。`comparison.png` 是静态总对比。

- `*-seated-before.png`：已安装的 12 张坐姿动作；`*-seated-after.png`：保留这些姿势、替换装饰圆凳的生成试稿。
- `*-transition-before.png`：已安装过渡；`*-transition-after.png`：以坐姿人物为主要画风参考重新绘制的第二轮过渡试稿。
- `*-display.png`：供预览使用的整帧裁切、缩放和定位图集。没有拆分、变形或单独旋转人物肢体。以头部尺度对齐，便于看画风；不是最终运行时校准。
- `prompts-v2.json`：当前试稿的生成提示；`prompts.json` 留存第一轮提示。第一轮过渡仍偏向旧画风，未采用。
- `frames.json`：预览裁切与头部测量记录。

坐姿循环预览沿用 0.25×，坐下、起身沿用 1×。本目录全部是待审阅素材，**0.8.7 安装包不包含这些替换稿，正式 assets 和用户动画倍速均未改变**。

生成式编辑保留动作设计，可能存在细微线条变化；本轮重点查看凳子和人物画风，以及过渡最后一帧与循环第一帧的衔接。原图保留透明通道，查看器若显示彩色底图，请以本页实际透明合成效果为准。
