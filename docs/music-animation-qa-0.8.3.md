# 0.8.3 音乐动作检查记录

本版使用内置 image_gen 重画完整人物帧。早期炽愿吉星草稿被用户指出仍是同一条腿向前，已弃用；最终版本重新以旧动画两个相反相位作为动作参考，绘制完整连接的关键姿势和中间姿势。

## 逐帧检查

- 每条腿沿大腿、膝盖、小腿到鞋子核对身份；观察前后两个极端姿势的遮挡变化，不能把“鞋子坐标变了”当作两条腿交替的证明。
- 炽愿吉星源图按阅读顺序并非正确时间顺序，校准文件重排为 `0,2,4,6,3,1,5,7`。导出的预览图集已按实际播放顺序排列。
- 三套坐姿均为八张完整人物图；正向再反向经过相邻帧，构成14步循环。没有拆开关节，没有插入旧骨骼合成帧，没有叠图模糊补帧。
- 用原待机检查各套的脸宽、明亮眼神、白发和服装；对冬祈新愿进一步缩短身体，对时砾逐光保持更紧凑的原始比例。坐姿按凳脚定位，同周期统一缩放。
- 深浅背景下检查实际 WPF 帧的头饰、头发、鞋子和透明边缘；脚部放大检查膝盖与小腿连接。源 PNG 的透明 RGB 预览颜色不作为边缘是否合格的依据。
- 时砾逐光轻微挥棒使用新绘六帧，取消额外的整体旋转。逐张检查胸前手腕、换重心、膝脚与首尾衔接。
